# RADWIMPS Archive

RADWIMPS とメンバーのインタビュー・対談を、年・メンバー・作品名で探せる索引サイトです。
記事の本文は載せず、タイトル・掲載日・媒体名と、掲載元へのリンクをまとめています。

- 公開サイト：https://ユーザー名.github.io/radwimps-interview-index/ （公開したら、この行を実際の URL に書き換えてください）
- **運用マニュアル：[docs/manual.md](docs/manual.md)**（公開のしかた・記事の追加・リンク切れへの対応）
- 記事データ作成ツール：公開サイトの `maker.html`

## できること

- 左上のメニューから、記事のカテゴリ（新作リリース・タイアップ・ライブ・ツアーなど、記事が生まれたきっかけ）・動画・あとで読む・記事を追加・マイページへ移動。管理者モードの端末には管理画面も出ます
- 一覧は年表のように年ごとにまとめて表示（YouTube の動画にはサムネイル付き）
- タイトル・人名・作品名での検索（ひらがな・カタカナ・ローマ字でも探せます）
- メンバー・種類・言語・年・作品での絞り込み、新しい順／古い順の並び替え
- お気に入り（★）・あとで読む・既読の記録（見る人のブラウザに保存。マイページからファイルにバックアップも可）
- 管理画面（URL の末尾に `#admin`）から、記事の追加・修正・非表示・削除をして、そのまま GitHub に保存（最初に一度だけ、GitHub で「合鍵」＝アクセストークンを作って登録）

## 記事を追加・修正するには

- **管理画面から**：記事を追加・修正して「GitHub に保存」を押します（準備はマニュアルの「[9. お気に入り・あとで読む・既読と管理画面](docs/manual.md#9-お気に入りあとで読む既読と管理画面)」）。
- **GitHub の画面から**：`data/articles.csv` を書き換えて保存（コミット）します（「[3. 記事を追加する](docs/manual.md#3-記事を追加する)」）。

どちらも1〜2分でサイトに反映されます。

## 自動で動くもの（GitHub Actions）

| ワークフロー | いつ | すること |
|---|---|---|
| サイトを公開する | `main` に保存したとき | 記事データの書式をチェックし、問題なければ GitHub Pages に公開。問題があれば公開を止めて通知 |
| リンク切れチェック | 毎週月曜 9:17ごろ（日本時間） | 全記事のリンクを確認し、対応が必要な記事を Issue でお知らせ |

## ファイル構成

```
index.html            サイトの骨組みと文章
maker.html            記事データ作成ツール
assets/
  style.css           見た目（色など）
  app.js              画面の動き（メニュー・検索・絞り込み・★・あとで読む・既読）
  admin.js            管理画面の「記事の管理」（記事の編集と GitHub への保存。管理画面を開いたときだけ読み込み）
  data.js             CSV の読み方と「書ける値」の決まり（サイトとチェック用プログラムで共通）
  config.js           設定（独自ドメインのときだけ使う）
  icon.svg            ブラウザのタブのアイコン
data/
  articles.csv        記事の一覧
  releases.csv        年ごとの主なリリース
tools/
  validate.mjs        書式チェック
  check-links.mjs     リンク確認
.github/workflows/    自動公開・自動チェックの設定
docs/manual.md        運用マニュアル
```

ビルドの手順や `npm install` は必要ありません。ファイルはそのまま公開されます。
チェック用プログラムは Node.js だけで動きます（`node tools/validate.mjs`）。

## 合鍵（アクセストークン）について

管理画面で使う合鍵は、登録した端末のブラウザ（localStorage）にだけ保存され、GitHub（api.github.com）以外には送られません。合鍵には、このリポジトリの「Contents」の読み書きだけを許可してください。

## 権利について

記事の本文・タイトルの権利は、各媒体と取材者にあります。この索引はリンク集として運営しています。
