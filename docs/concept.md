# RADWIMPS Archives 正式版コンセプト書

正式版を作るときの判断の基準。迷ったら、ここに戻る。
11/19 に、コンセプトの8項目と正式版の中身・ベータ版の閉鎖の方針を、すべて決めた。
11/19 の続きで、夜空・窓・同居人（羊）を決めた。

## 一文

**RADWIMPSが語ってきた言葉が住んでいる家。**

時間はいつも夜。灯りのついた窓から部屋に入り、知らなかった言葉に出会う。気に入った言葉は、自分の棚に持ち帰る。
散らかったら、この家に住みついている羊が、夜のあいだに数えて片付けておいてくれる。

## 1. 誰のためか

**長く聴いてきた人を、いちばん大事にする。**

- 入門の説明より、正確さ・出典・日付・深さを優先する。
- 「あの時こう言っていた」を、うろ覚えでも探し当てられること。
- 知っている人を退屈させない。初めての人向けの案内は、邪魔にならない場所に置く。
- 同居人の可愛さは、探す・読む邪魔をしない範囲で出す。

## 2. 何を持ち帰ってほしいか

**知らなかった言葉に、出会えた。**

長く聴いてきた人は、有名な発言はもう知っている。その人がまだ読んでいない言葉に出会わせることが、このサイトのいちばんの価値。

- 玄関（トップ）の主役は「出会い」。
- 検索は大きく置くが、出会いを支える道具。
- 運営が記事を集め続ける（受け取る側）ことと、ユーザーが棚に集める（集める側）ことを、両方持つ。

## 3. 世界観（家・部屋・棚）

- **たとえの強さ**：ページ名は今のまま分かりやすく（記事一覧・歩み・RAD LIVE SET LIST・楽曲一覧・メンバー紹介）。小さな添え書き・入口の絵・案内文で「部屋」を感じさせる。メニューを部屋の名前に置き換えることはしない。
- **部屋（6つ）**：記事一覧・歩み・RAD LIVE SET LIST・楽曲一覧・メンバー紹介・あなたの棚
  - 楽曲一覧は別のブランチ（claude/project-thread-n9s9s7 の songs.html）にある。正式版の作業に取り込み、ほかの部屋と同じ見た目にする。
- **夜の家**：時間はいつも夜。背景は窓の外の夜空。夜空は押し出しすぎない。
  - 空のテーマ（青空・夕焼け・夜空）を選べるようにする案は、世界観の押し付けになるのでやめた。夜空だけ。
- **入口は扉ではなく窓**：玄関に並べる各部屋の入口は、夜の家の「灯りのついた窓」。外（夜空）から部屋をのぞくように入る。窓の中は少し明るい青で、文字を読みやすくする。
- **玄関（トップ）**：全件を並べない。いちばん大きく「まだ読んでいない一節」を置く。
  - 既読の記録から、その人がまだ読んでいない記事を1本選ぶ（初めての人には、日替わりの1本と同じになる）。
  - 出す文は、運営が書いた紹介文（「説明」）。記事の本文や発言の引用は使わない。
  - その下に、各部屋への入口（灯りのついた窓）を並べる。
- **あなたの棚**：お気に入り・あとで読む・既読・参加した公演を1か所に集める。どの部屋からでも棚に入れられる。人・曲・年代・ライブごとに自動で分かれて並ぶ。
  - 正式版では、保存はブラウザの中（ログインなし）。
  - **パソコンとスマホの同期は、正式版のあとに足す**（ログインと保存先の準備が要るため）。正式版の保存の形は、同期を足しやすいように作る。それまでは「引き継ぎ用のリンク」で移せる。

## 4. 同居人（キャラクター）＝羊

- この家に住みついている**羊**。前に考えていた「目のないウサギのような同居人」から置き換えた。
- **姿・雰囲気は、イラストレーターに任せる**（ここでは決めない）。
- **話さない**。小さなメモ（書き置き）と身ぶりだけ。
- メモの言い回しに、羊らしく「数える」をさりげなく入れる。例：「今夜は12件、数えておきました」。羊だと知らなくても自然に読めること。
- 出てくる場所：棚を片付けたとき・棚が空のとき・検索で見つからないとき・お知らせ。
- **名前は、絵ができてから決める**。
- **正式版は、羊の絵ができてから公開する**。公開日は絵の完成しだいで、年内は約束しない。

### 絵の依頼（依頼先はこれから探す）

依頼で伝える条件
- 夜の群青（黒〜群青の夜空）の上で映えること。
- 可愛らしく、親しみやすいこと。
- 使う場面ごとの絵を数枚（片付けたとき・棚が空のとき・見つからないとき・お知らせ・案内ページなど）。話さないので、身ぶりで伝わること。
- 権利と納品の形：**サイトと SNS（X・共有画像・メール）で使える範囲**。色や大きさの小さな調整を含む。拡大しても粗くならない形（SVG か大きな PNG）。

伝えないこと（描く人の自由）
- 姿・雰囲気・画風。
- 公式や他のキャラクター（MeeMo など）に似ていないかは、依頼には書かず、上がった絵を運営が確かめる（「やらないこと」の決まりはそのまま）。

## 5. AI の使いどころ

- **運営の作業だけで使う**：記事を追加するとき、説明文・タグ・分類の下書きを AI が作り、運営が確かめて保存する。
- ユーザーの棚の片付けは、記事に付いたタグ（人・曲・年代・ライブ）で行う。正確で、費用もかからない。
- **ユーザーに「AI」という言葉は見せない**。片付けは「同居人がやってくれたこと」として見せる。

## 6. 言葉づかい

- **静かで短い、少し詩的**。今の「まだ知らない言葉が、きっとある。」の路線を強める。
- 丁寧語が基本。入口・添え書き・同居人のメモは短い言い切りでよい。
- 操作の説明（ボタン・エラー・設定）は、分かりやすさを優先する。
- 「夜」を匂わせる言葉（今夜・おやすみなさい など）は、**羊のメモだけ**に使う。見出しや操作の文は普通に書く（昼に来た人にも違和感がないように）。

## 7. 見た目の決まり

- 群青 #1A3FA8・青みの黒 #0A0B12・白は変えない（design/blue-theme の配色）。
- **夜空の質感**：背景の黒→群青のグラデーションはそのまま。布の質感・染めむらは、**ごく薄い星**に置き換える。
  - **星は動かさない**（瞬きも流れ星もなし）。押し出しすぎず、軽く、読む邪魔をしない。
- 玄関の入口は灯りのついた窓。部屋の違いは**夜の青の濃淡**で出す（差し色は足さない）。手刷りのざらつきは使わない。
- 英語の太い見出しと、日本語の小さな添え書き（今の「RADWIMPS ARCHIVES」の流れ）。
- **青の配色は、正式版で初めて公開する**（ベータ版には出さない）。
- 守ること：CSP（インラインの style・script 禁止）、文字12px以上（スマホのプルダウンは16px）、コントラスト4.5以上（線やアイコンは3以上）、押せる範囲44px程度。

## 8. やらないこと

- 運営が集めた記事を、全部玄関に並べない。
- ユーザーに「AI」と見せない。
- 記事の本文（発言の引用を含む）は載せない。
- 公式と紛らわしくしない：「ボクンチ」「〇〇 ROOM」の名前、ドアの絵、公式のロゴや写真を使わない。
- 人気順で煽らない：閲覧数のランキングや「いま話題」を出さない。古い記事が埋もれないようにする。
- 有料会員（ボクンチなど）の中身に触れない。載せず、紹介もしない。

- **11/30（月）23:59 に閉じる**。それ以降は「正式版の準備中」の案内ページだけを出す。
- **予告**：今から、ベータ版の上部の案内に出す（config.js の closing と x）。
  - 文面：「このベータ版は 11月30日（月）23:59 で公開を終えます。正式版は近日公開します。公開日は X（@cameradic_man）でお知らせします。保存データ（お気に入り・あとで読む・既読・参加した公演）は、このブラウザに残ります。念のため、お気に入り・あとで読む・既読は保存データの管理からファイルに書き出しておけます。」
- **案内ページ**：夜空の背景（青の配色）で、正式版の予告を兼ねる。窓や羊はまだ出さない。
  - 載せるもの：準備中であること、保存データはブラウザに残ること、X（@cameradic_man）へのリンク、公開のお知らせメールの登録欄。
- **23:59 の切り替えは自動では起きない**。30日の夜に、案内ページを本番（main）に反映する。
- **保存データ**：ブラウザの中にあるので、案内ページに差し替えても消えない。消す処理は入れない。
