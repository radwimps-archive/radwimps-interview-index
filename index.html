記録のバックアップ

お気に入り・あとで読む・既読は、いま使っているブラウザだけに保存されています。ファイルに書き出しておけば、ブラウザのデータを消したあとや別の端末でも、読み込んで元に戻せます。読み込んでも、今ある記録は消えません。

この端末は管理者モードです。メニューに「管理画面」が出ています。

管理画面は、管理者の端末だけに出る画面です。この端末で管理者モードをオンにすると、メニューに「管理画面」が出ます（ほかの人の端末には出ません）。

管理画面では、記事の追加・編集・非表示・削除をして、GitHub に保存できます。保存には、管理者が GitHub で作る「合鍵」が必要なので、ほかの人が管理者モードをオンにしても記事は変えられません。

      GitHub Pages（○○.github.io）で公開すると、ここに GitHub の画面へのリンクが出ます。独自ドメインのときは、assets/config.js の repoUrl に GitHub の URL を書いてください。

      この索引に載っていないインタビューやライブレポートを見つけたら、教えてください。管理者が中身を確かめてから追加します。

      GitHub で送る

      送るには GitHub のアカウント（無料）が必要です。押すと GitHub の画面が開くので、内容を確かめて「Submit new issue」を押してください。

      RADWIMPS とメンバーのインタビュー・対談・ライブレポートを、年ごとにまとめた索引です。タイトルを押すと、掲載元のページが開きます。

      この索引は、記事や動画のタイトル・掲載日・媒体名と、掲載元へのリンクをまとめたものです。リンク先でインタビューやライブレポートの内容が読める・見られるものを載せています（有料会員限定のものは載せていません）。本文や動画の権利は、各媒体と取材者にあります。

      掲載日が「年」や「年・月」までのものは、確認できた範囲で記載しています（掲載日がわからないライブレポートは、公演の年・月にしています）。掲載元のタイトルを確認できなかった記事には、内容がわかる見出しを付けています。「雑誌・ムック」の記事は、誌面のインタビューの一部を紹介しているウェブ記事です。

      リンクは定期的に確認し、開けなくなった記事は一覧から外しています。

      記事の誤りやリンク切れに気づいたら、こちらから知らせてください（GitHub のアカウントが必要です）。

      主な出典：RADWIMPS 公式サイトの MEDIA 欄（WEB）、各媒体の記事ページ。
